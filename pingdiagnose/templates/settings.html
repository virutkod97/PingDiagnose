Chứng chỉ HTTPS

Để trình duyệt không báo "Không bảo mật", máy trạm cần tin cậy chứng chỉ của PingDiagnose. Chọn một cách:

  1. Từng máy: tải và chạy PingDiagnose-cai-chung-chi.bat, bấm Yes, đóng hết trình duyệt rồi mở lại. (Hoặc tải ca.crt → mở → Install Certificate → Trusted Root Certification Authorities.)
  2. Cả domain (Active Directory): Group Policy → Computer Configuration → Windows Settings → Security Settings → Public Key Policies → Trusted Root Certification Authorities → Import file ca.crt.
  3. Dùng chứng chỉ có sẵn của công ty (wildcard hoặc do CA nội bộ của AD cấp): trên máy chủ chạy PingDiagnose.exe cert --import chungchi.pfx --password matkhau rồi khởi động lại service. Máy trạm không cần làm gì.
